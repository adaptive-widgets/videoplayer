# RxPlayer

> A modern, lightweight React video player built with TypeScript, hooks, and enterprise-grade architecture.

## 🚀 Features

RxPlayer provides a complete video solution with intuitive APIs, comprehensive customization options, and professional-grade performance. Built from the ground up with modern React patterns and TypeScript.

## 🏗️ Architecture & Performance

### Modern React Foundation
- **TypeScript-First**: Complete type safety with comprehensive interfaces
- **React Hooks & Context**: State management using `useReducer` and context API
- **Modular Design**: Separation of concerns with context, hooks, reducer, and provider
- **Vite-Powered**: Lightning-fast development and optimized builds
- **Tree-Shakable**: Import only what you need for optimal bundle size
- **Memory Efficient**: Smart player registry management

### Performance Optimization
- **Lightweight Bundle**: < 50KB gzipped
- **Fast Initialization**: < 100ms setup time
- **Lazy Loading**: Components loaded on demand
- **Resource Management**: Efficient memory and CPU usage
- **Mobile Optimized**: Battery-efficient playback on mobile devices

### Developer Experience
- **Simple API**: Intuitive `createPlayer()` and `usePlayer()` hooks
- **Easy Integration**: Drop-in setup with minimal configuration
- **TypeScript Support**: Full type definitions and IntelliSense
- **Hot Reloading**: Instant development feedback
- **Modern Tooling**: Built-in ESLint, Prettier, and testing support

## 🎥 Video Features (v1.0)

### Multi-Source Support
- **HTML5 Video**: MP4, WebM, OGV format support
- **Streaming**: HLS (HTTP Live Streaming) and DASH support
- **External Sources**: YouTube, Vimeo, Twitch integration
- **Fallback Chains**: Automatic quality adjustment and source fallback
- **CDN Optimization**: Optimized loading from content delivery networks

### Player Controls
- **Custom Control Bar**: Fully themeable and customizable components
- **Keyboard Shortcuts**: Spacebar (play/pause), arrow keys (seek), volume control
- **Touch Gestures**: Mobile-optimized touch controls and gestures
- **Picture-in-Picture**: Native PiP support across browsers
- **Fullscreen**: Full browser and video-only fullscreen modes
- **Custom Positioning**: Flexible control positioning and layout

### Quality & Performance
- **Adaptive Streaming**: Automatic bitrate adjustment based on network conditions
- **Preloading**: Configurable preloading strategies (metadata, auto, none)
- **Buffer Optimization**: Smart buffering to prevent interruptions
- **Network Awareness**: Quality selection based on connection speed
- **Performance Monitoring**: Built-in metrics and performance tracking

### Rich Media
- **Subtitles & Captions**: SRT, VTT, WebVTT format support
- **Multiple Audio Tracks**: Support for multiple audio streams
- **Chapter Navigation**: Chapter markers and timeline navigation
- **Thumbnail Previews**: Video thumbnails on seek/hover
- **Custom Overlays**: Support for annotations and custom overlays
- **Screen Recording**: Built-in screen capture capabilities

### Accessibility & Internationalization
- **WCAG 2.1 AA Compliance**: Full accessibility standard compliance
- **Screen Reader Support**: Comprehensive screen reader compatibility
- **Keyboard Navigation**: Complete keyboard accessibility
- **High Contrast Mode**: Support for high contrast themes
- **Multi-language Interface**: Internationalization support
- **RTL Support**: Right-to-left language support
- **Audio Descriptions**: Support for audio description tracks

### Customization
- **Theme System**: CSS variable-based theming
- **Component Styling**: Granular component-level customization
- **Brand Integration**: Logo, watermark, and brand color support
- **Custom Animations**: Configurable loading and transition animations
- **Responsive Design**: Mobile-first responsive layout system
- **Skin Builder**: Visual theme customization tools

## Plugin Specifications

### Performance Targets
- **Bundle Size**: < 50KB gzipped
- **Initialization**: < 100ms
- **Memory Usage**: < 10MB per player instance
- **Browser Support**: Chrome 80+, Firefox 75+, Safari 13+, Edge 80+

### Compatibility
- **React**: 18.x, 19.x
- **TypeScript**: 4.5+
- **Node.js**: 16+
- **Build Tools**: Vite, Webpack, Rollup

### Installation
```bash
npm install rxplayer
# or
yarn add rxplayer
```
